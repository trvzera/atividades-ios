# Chamada

Atividade de Desenvolvimento iOS — Capítulo 7, exercício 2.

Inclusão de alunos, presença por toque, filtros e exclusão pelo ID do item visível.

## Executar

1. Abra `Chamada.xcodeproj` no Xcode.
2. Selecione o scheme `Chamada` e um simulador de iPhone.
3. Execute com **⌘R**.

Requer iOS 17 ou superior e Xcode com o SDK correspondente. Não há dependências externas. Para um iPhone físico, selecione seu time de assinatura no Xcode.

## Organização e estudo
