# Estante

Atividade de Desenvolvimento iOS — Revisão, exercício 1.

Livros em um único ViewModel; inclusão, exclusão, marcação de leitura pelo ID e resumo de páginas lidas.

## Executar

1. Abra `Estante.xcodeproj` no Xcode.
2. Selecione o scheme `Estante` e um simulador de iPhone.
3. Execute com **⌘R**.

Requer iOS 17 ou superior e Xcode com o SDK correspondente. Não há dependências externas. Para um iPhone físico, selecione seu time de assinatura no Xcode.

## Organização e estudo

O código está em [`Estante/`](./Estante/). O [enunciado](./ENUNCIADO.md) e as imagens de referência do professor estão incluídos para comparação.
